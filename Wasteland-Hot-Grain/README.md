# Wasteland — The Hot Grain

A post-apocalyptic Firefox theme with warm dust, rust, and hot grain tones.

## Features

- Deep dusty brown backgrounds (`#1A1410`, `#2A221C`)
- Rusty sienna active tab (`#8B4513`) with hot grain accent
- Warm wheat-colored text (`#F5E0B3`) for readability
- Rounded address bar with rust-colored border
- Burnt orange icons (`#D5560C`) for a scorched look
- Dark popups, menus, and sidebars
- Works in both light and dark OS modes
- No data collection, no tracking, no external requests

## Installation

### From addons.mozilla.org (Recommended)

👉 [Install Wasteland — The Hot Grain](https://addons.mozilla.org/de/firefox/addon/wasteland-hot-grain/)

### Manually

1. Download the latest `.xpi` from the [Releases](../../releases) page.
2. Open Firefox → `about:addons` → gear icon → **Install Add-on From File…**
3. Select the `.xpi` file.

## Compatibility

- Firefox 63 or newer
- Windows, macOS, and Linux

## Technical Notes

> **Note:** The add-on ID `wasteland-hot-grain@tohub.rf.gd` is not an email address. It is a unique identifier required by Firefox.

## Development

This theme is a pure WebExtension theme. The only file needed to modify is `manifest.json`.

To test changes locally:
1. Open Firefox → `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…**
3. Select `manifest.json`
