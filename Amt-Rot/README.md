# Amt-Rot

A dark Firefox theme inspired by the official red and grey design of German administrative authorities.

## Features

- Deep dark backgrounds (`#1A1A1A`) with official red accents (`#D21F26`)
- Active tab highlighted in the signature red color
- Rounded address bar with a red border
- Dark popups, menus, and sidebars
- Clean, minimalist, and easy on the eyes
- Works in both light and dark OS modes
- No data collection, no tracking, no external requests

## Installation

### From addons.mozilla.org (Recommended)

👉 [Install Amt-Rot](https://addons.mozilla.org/de/firefox/addon/amt-rot/)

### Manually

1. Download the latest `.xpi` from the [Releases](../../releases) page.
2. Open Firefox → `about:addons` → gear icon → **Install Add-on From File…**
3. Select the `.xpi` file.

## Compatibility

- Firefox 63 or newer
- Windows, macOS, and Linux

## Technical Notes

> **Note:** The add-on ID `amt-rot@tohub.rf.gd` is not an email address. It is a unique identifier required by Firefox.

## Development

This theme is a pure WebExtension theme. The only file needed to modify is `manifest.json`.

To test changes locally:
1. Open Firefox → `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…**
3. Select `manifest.json`
